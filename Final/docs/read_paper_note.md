3. A brief Description of the CNN Architecture
    每张图像都表示为像素矩阵，其中黑色像素对应0，白色像素对应255。本次研究将CNN作为给予原始图像数据预测的主力模型，因为CNN施加了跨参数限制，极大减少了参数数量，更加易于训练，在相对较小的数据集中的预测表现也更加出色。并且，CNN嵌入了多种工具，使得他能够应对图像中重要物体的变形和重定位问题。CNN的建模方案本质上有模块化特征，采用单一核心构建模块，可以根据应用以不同的配置进行组合，核心构建模块包括三种操作：convolution卷积、activation激活和pooling池化。 Convolution的基本原理与kernel smoothing核平滑类似，会在图像上进行水平和垂直扫描，并且针对图像矩阵中的每个元素，对其紧邻周边区域的图像内容进行汇总；Activation是一种非线性变化，具体为使用leaky ReLU函数，按元素应用于卷积滤波器的输出结果。Pooling同样会在输入矩阵上进行扫描，返回图像周边区域的最大值，以此降低数据维度并减少噪声。CNN的最后一层为全连接层，由softmax函数激活。这个CNN针对二分类结果进行建模：在指定的未来时间窗内实现正收益时结果为1，否则为0.因此，CNN的拟合值是对出现正收益这一结果概率的估计。
    我们考虑三种复杂程度不同的主要CNN结构。
    （1）第一种是5天的卷积神经网络模型结构，由2个卷积神经网络构建块组成。结构如下：（以下使用H*W来表示卷积神经网络构建快的输出尺寸，H表示高度，W为宽度）
    32*15的5天的image输入给第一个卷积神经网络构建块，这个模块包括：“5*3conv,64”（conv表示卷积，后面的数字代表通道深度（通道数量，例如64，128，256，512））经过LReLU到“2*1 Max-Pool（Max-Pool表示最大池化）”。
    然后第一个模块传给第二个模块，第二个模块包括“5*3conv,128”经过LReLU到“2*1 Max-Pool”。
    第二个模块输入到全连接层（FC）：FC X， 其中这个X表示全连接层厚的输入尺寸，由最后一个卷积神经网络构建快的H*W*D乘积计算得出。
    最终再从FC X传输到Softmax层，输出“上涨”和“下跌”的概率。
    （2）第二种是20天的卷积神经网络模型结构，由3个卷积神经网络构建块组成。结构如下：
    64*60的20天的image输入给第一个卷积神经网络构建块，这个模块包括：“5*3conv,64”经过LReLU到“2*1 Max-Pool”。
    然后第一个模块传给第二个模块，第二个模块包括“5*3conv,128”经过LReLU到“2*1 Max-Pool”；
    第二个模块输入到第三个模块，第三个模块包括“5*3conv,256”经过LReLU到“2*1 Max-Pool”；
    第三个模块输入到全连接层（FC）：FC X， 其中这个X表示全连接层厚的输入尺寸，由最后一个卷积神经网络构建快的H*W*D乘积计算得出。
    最终再从FC X传输到Softmax层，输出“上涨”和“下跌”的概率。
    （3）第三种是60天的卷积神经网络模型结构，由3个卷积神经网络构建块组成。结构如下：
    96*180的60天的image输入给第一个卷积神经网络构建块，这个模块包括：“5*3conv,64”经过LReLU到“2*1 Max-Pool”。
    然后第一个模块传给第二个模块，第二个模块包括“5*3conv,128”经过LReLU到“2*1 Max-Pool”；
    第二个模块输入到第三个模块，第三个模块包括“5*3conv,256”经过LReLU到“2*1 Max-Pool”；
    第三个模块输入到第四个模块，第四个模块包括“5*3conv,512”经过LReLU到“2*1 Max-Pool”；
    第四个模块输入到全连接层（FC）：FC X， 其中这个X表示全连接层厚的输入尺寸，由最后一个卷积神经网络构建快的H*W*D乘积计算得出。
    最终再从FC X传输到Softmax层，输出“上涨”和“下跌”的概率。
4. Image REpresentation versus Times-Series Representation图像表示与时间序列表示
    1D和2D描述了CNN的卷积滤波器在数据中的移动方式，黑白图像以矩阵形式表示，矩阵中每个元素的值对应图像相应位置的灰度深浅。由于标准图像处理CNN的矩形滤波器会在图像矩阵中同时沿水平和垂直方向移动，因此这类CNN称为“2D卷积神经网络”；而“1D卷积神经网络”是将CNN应用于时间序列数据，在这种情况下，数据同样以矩阵形式表示，行代表时间，列代表变量，此时的卷积滤波器宽度与数据矩阵一致，且滤波器仅沿时间维度移动。
    本次研究的实验设计是采取“2D卷积神经网络”来进行预测分析。因为讲数据表示为图像，能够使得卷积滤波器捕捉不同价格曲线之间的非线性空间关联。
    应用于价格走势图的二维卷积神经网络，可通过将"无变化""小幅上涨"和"大幅上涨"视为独立特征的32滤波器，以不同权重做出最终预测。也就是说，当这些滤波器作用于图像时，其作用类似于指示函数，能够识别并对不同幅度的价格波动进行分类。同样地，该图像会将价格方向走势、相对于移动平均趋势的变动、价格波动性以及交易量信息自动整合到单一表征中。例如，若要同时考量价格方向与波动性，传统的时间序列模型需要做出限制性设定，手动构建特征。此外，纳入波动性信息还不可避免地需要借助随机波动或GARCH模型等方法对价格序列进行非线性变换。而二维卷积神经网络(2DCNN)的优势就在于，它完全无需手动构建此类特征，而是从卷积神经网络内部的市场数据序列中提取预测模式。
    简而言之，以图像形式摄入数据能让模型识别出那些时间序列法可能难以发现的数据关系。正如人类通过图形比通过数字列表更容易识别模式一样，统计模式识别算法也能从将整个数据矩阵可视化成单张图像中获益。
